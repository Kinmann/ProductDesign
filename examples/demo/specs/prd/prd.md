# 회원 서비스 PRD

## 목표
- 가입 완료율을 높이고, 계정 보안 사고를 줄인다.

## 대상 사용자
- 서비스를 처음 쓰는 방문자
- 이미 가입한 회원

## 범위
- 포함: 이메일 회원가입, 로그인, 비밀번호 변경
- 제외: 소셜 로그인, 휴대폰 본인 인증

## 성공 지표
- 가입 시작 대비 가입 완료율 70% 이상
- 비밀번호 관련 고객 문의 월 20건 이하

## 기능 목록

### FEAT-SIGNUP 회원가입
- 설명: 방문자가 이메일로 계정을 만든다.

### FEAT-LOGIN 로그인
- 설명: 회원이 이메일과 비밀번호로 로그인한다.

### FEAT-ACCOUNT 계정 관리
- 설명: 회원이 자기 정보를 보고 비밀번호를 바꾼다.
- 의존: [[FEAT-LOGIN]] (로그인한 회원만 접근), [[FEAT-SIGNUP]] (가입 때 입력한 정보를 보여줌)
